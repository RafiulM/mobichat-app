## Default Permission

Default permissions for the TTS plugin

#### This default permission set includes the following:

- `allow-start-tts-server`
- `allow-stop-tts-server`
- `allow-get-tts-port`
- `allow-is-tts-running`
- `allow-request-microphone-permission`
- `allow-get-microphone-status`
- `allow-open-microphone-settings`
- `allow-request-microphone-via-helper`
- `allow-start-native-stt`
- `allow-restart-native-stt`
- `allow-stop-native-stt`
- `allow-cancel-native-stt`
- `allow-cancel-native-stt-keep-engine`
- `allow-get-stt-authorization-status`
- `allow-request-stt-authorization`
